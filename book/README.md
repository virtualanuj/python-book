# Practical Python: Building a Product Step by Step

A book written alongside the ThreatDesk course. Each chapter covers what one lesson taught, in reference form: the concepts, the idioms, the pitfalls, and the code ThreatDesk gained. Read a chapter after finishing its lesson, and come back to it later when you need a refresher.

Target: CPython 3.14, managed with uv.
